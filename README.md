# ttrpg-city-builder

Песочница роста поселения для настольных ролевых игр. Показывает прогрессию
численности во времени, позволяет встать в любой год и посмотреть срез:
население, фаза, темп роста, доступные строения и что упирается в потолок.

Сеттинг — усреднённое тёмное фэнтези: магия есть, но доступна не каждому, а
технологии развиваются с оглядкой на магию (в сильно магических регионах часть
технических зданий не разблокируется, и наоборот).

## Модель

Логистический рост `r·P·(1 − P/K)` плюс миграция как доля разрыва до потолка `K`.

- **K (несущая ёмкость)** зависит от плодородия × воды, транспорта (завоз еды
  резко поднимает потолок), безопасности, санитарии и магии.
- **Санитария** добавляет скрытую «городскую смертность»; **лечебная магия** её
  гасит и поднимает K.
- **Капитал спонсора** сжимает «детство» поселения первые N лет.
- **Шоки** (чума / неурожай / набег / пожар) детерминированы зерном ГСЧ —
  один и тот же seed даёт один и тот же расклад.

Числа намеренно «играбельные»: это прикидка динамики для стола, не симулятор
реальности.

## Архитектура

Слоистая, данные отделены от представления.

```
src/
├── domain/      чистый TS: модель симуляции. Без React, без строк — только id.
│   ├── types.ts      контракты данных
│   ├── simulate.ts   (SimParams) => SimResult — pure, детерминированная функция
│   ├── archetypes.ts типы основания · buildings.ts здания · phases.ts фазы
│   └── rng.ts        детерминированный ГСЧ (mulberry32)
├── i18n/        локализация: id → строки (ru/en), Intl-форматирование чисел.
│   └── locales/{en,ru}.ts  (en задаёт форму типа Messages, ru обязан совпадать)
├── state/       мост домена и UI: reducer параметров + мемоизированный селектор.
├── components/  тупые презентационные компоненты, тянут строки через useI18n().
└── lib/ui.ts    UI-константы (цвета фаз/тегов).
```

Доменный слой ничего не знает про React и язык: здания, фазы и события несут
стабильные `id`, а строки живут только в `i18n`. Поэтому модель тестируется в
изоляции, а добавить язык — это один файл в `locales/` (компилятор подскажет
недостающие ключи).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build
npm run preview  # предпросмотр production-сборки
```

## prototype/

`prototype/settlement-calc.html` — исходный одностраничный прототип (один HTML-файл,
открывается двойным кликом, без сборки). React-версия — его развитие.
